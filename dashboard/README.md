# `dashboard/` — Public reliability + volume telemetry (DIRECTIVE §6)

The public reliability dashboard is **served live** by the consumer web app at the
**`/dashboard`** route (`apps/web/app/dashboard/page.tsx`), not as a separate
deployment.

## Why it lives in `apps/web`, not as a standalone app

The dashboard and the consumer frontend share three things that must **never
drift apart**:

1. **The design system (§11).** Both use the exact same tokens, `.card` / `.chip`
   / `.stat-num` anatomy, and the §11.7 proof/evidence grid. Duplicating the
   design system across two apps is the fastest way to introduce the pixel drift
   §11.10 forbids.
2. **The live data layer (`apps/web/lib/onchain.ts`).** Every number on the
   dashboard is read from the same server-side onchain reader the arena uses —
   `HandlerSucceeded` / `HandlerFailed` / `HandlerSkipped`, fallback-trigger
   counts, per-division win rate, and volume. One source, one truth.
3. **The "no mock data, ever" guarantee (§3).** Sharing the reader means there is
   exactly one code path that can produce a displayed number, and it always comes
   from chain/REST.

## What it shows (all live, all onchain — §6)

- Reactive success rate (last 24h / 7d), sourced from subscriber telemetry events.
- Average latency from price event → order placement (ms + block).
- Count of fallback-watcher activations and how each resolved (a **distinct**
  metric from reactive successes, per §4.5).
- Event Contracts trading volume generated by Cadence agents.
- Per-division (Reactive vs AI-assisted) win rate + ROI, and AI signal quality.
- SOMI balance / burn rate for the subscriber and each vault (§4.3).

Every metric card names its own provenance (`last 24h · onchain`, etc.) — the
same honesty-signalling function as the reference's `machine-checked` tags.

## Run it

```bash
pnpm --filter @cadence/web dev
# then open http://localhost:3000/dashboard
```

Before any agents are seeded (pre-Phase-3), the page renders the honest dashed
empty state (§11.8) — it never backfills or simulates history.
